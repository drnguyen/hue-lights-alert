Endpoints

MethodPathDescription
POST/api/v1/alertStart an alert. Replaces any running alert.
GET/api/v1/alertCurrent alert state.
DELETE/api/v1/alertClear the alert and restore the lights to their previous state.
GET/api/v1/healthLiveness + pairing status. No auth.

Request body for POST /api/v1/alert

FieldValuesNotes
levelamber · redRequired. Amber = #FFBF00, Red = #FF0000.
modeglow · deadRequired. glow pulses between min and max brightness; dead is a static colour at max brightness.
duration_seconds1 – 86400Optional. Auto-clear after this many seconds; omit to keep the alert until DELETE.

Responses

  • 200 — {"status": "started", "alert": {"active": true, "level": "red", "mode": "glow", "started_at": "…", "expires_at": null, "light_ids": ["1","2"], "source": "api:monitoring"}}
  • 401 — invalid or missing token
  • 409 — no bridge paired or no lights selected
  • 422 — invalid body (unknown level/mode, bad duration)

Examples

# Red, glowing, until cleared
curl -X POST {{ base_url }}/api/v1/alert \
  -H "Authorization: Bearer $HUE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"level": "red", "mode": "glow"}'

# Amber, static, auto-clear after 5 minutes
curl -X POST {{ base_url }}/api/v1/alert \
  -H "Authorization: Bearer $HUE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"level": "amber", "mode": "dead", "duration_seconds": 300}'

# Status
curl {{ base_url }}/api/v1/alert -H "Authorization: Bearer $HUE_TOKEN"

# Clear
curl -X DELETE {{ base_url }}/api/v1/alert -H "Authorization: Bearer $HUE_TOKEN"
